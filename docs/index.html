A "Boring but Functional" Frontend Calculator

This project has two main pages. Pick where you want to go:

Open Calculator Open Test Dashboard

What you will get

  • A working calculator with decimal, operators, and parentheses support
  • Keyboard input support: Enter, Backspace, Escape, and C
  • A visual test page that shows pass/fail step by step
  • Clear explanations of what each test checks and why it matters

What to test manually

Try these quick checks directly on the calculator page:

  • Basic operations: test 2+2, 5-3, 8/2, then press = and verify correct answers.
  • Order of operations: try 2+3*4 and confirm the result is 14.
  • Parentheses behavior: compare (2+3)*4 with 2+(3*4) and confirm they produce different correct results.
  • Negative numbers: test -5+3 and 2--3 to confirm unary and double-minus logic.
  • Decimal precision: run 0.1+0.2, 5.5/2, and (0.1+0.2)*10.
  • Multiplication input equivalence: enter 2x3, 2X3, and 2*3; all three should return 6.
  • Keyboard controls: use Enter to calculate, Backspace to delete one character, and Escape or C to clear.
  • Error handling: try 1/0 and an invalid expression like 2+) to check clear validation/error feedback.

Built with basic HTML, CSS, and JavaScript for learning and practical frontend calculation handling.
